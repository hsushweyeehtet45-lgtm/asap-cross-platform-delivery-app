
# ASAP – Cross-Platform Delivery App prototype designed in Figma for web, mobile, and wearable devices.

🔗 Figma Design:
PASTE_YOUR_FIGMA_LINK_HERE

ASAP is a cross-platform delivery application designed to provide a consistent user experience across desktop, mobile, and smartwatch devices. The project focuses on creating an intuitive delivery service interface that allows users to track orders, manage deliveries, and access services seamlessly across different platforms.
For this project, I worked as a UI/UX Designer and was responsible for designing user flows, wireframes, and high-fidelity interfaces in Figma. The design process emphasized usability, accessibility, and visual consistency to ensure a smooth experience regardless of device type.

**Technologies:** Figma, Wireframing, Prototyping, User Flow Design
